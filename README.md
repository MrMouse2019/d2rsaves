## 使用和回存

1. 从`index.json`找到目标流派的当前存档目录。
2. 通常退出游戏，先备份国服目录中的同名人物，再复制所需文件。用户已明确约定修改期间不使用目标离线人物时，可在游戏进程运行或游玩其他人物时同步，写入前仍核对目标文件未变。
3. 进入游戏“离线”角色列表，选择对应人物实测。
4. 测试通过后，从国服目录回存最新人物，保留修改前版本并更新SHA256校验清单。

本机归档目录为`E:\game\d2rsaves`，国服默认存档目录为`%USERPROFILE%\Saved Games\Diablo II Resurrected (CN)`；其他电脑应使用自己的实际目录。

允许在游戏运行时编辑归档目录中的模板。2026-10-19用户进一步授权每轮同时更新国服与归档，并保证目标离线人物不在游玩中；该约定有效时可直接备份、修改、同步和核验，无需反复等待游戏进程退出。以最新国服快照为来源，若写入前目标已变化则重新取得最新来源。完整约定见 [归档与测评流程.txt](归档与测评流程.txt)。

## 配装与交付约定

- 毕业装备按正常可获得的属性范围取满变量，互斥词条按BD选择一项。
- 需要破免板时使用相应升级版本，检查实际物品类型和属性。
- 超级野蛮人新版暗金宝珠最多镶嵌一颗，普通彩虹刻面另计。
- 人物背包默认携带：赫拉迪姆方块、回城书、辨识书、一串钥匙、暗金火炬和毁灭、对应升级破免板、技能板，以及补充抗性、FHR或生命法力的小护身符。工具和护符按实际尺寸排布。
- 投石索提供回城时，可按用户选择省去回城书并调整技能板布局；默认双书规则不因此取消，也不强行回退用户当前布局。
- 所有角色按实际腰带容量填满大紫药水。

## 更新记录规则

每个BD的制作、调整、测试记录和实测回存使用独立的`codex/<流派名称>`特性分支；合入及提交推送分别按用户授权执行。

每次合入或发布都更新 [CHANGELOG.md](CHANGELOG.md)，说明职业、流派、修改内容、验证结果和兼容性影响。未发布的修改先写入“未发布”；发布时归档到明确版本和日期。

新增流派时同步更新`index.json`和上面的索引表；修改当前存档时更新该目录校验清单和本页当前版本信息。原存档和历史备份保留，不覆盖历史文件来伪造旧版本。
