## 使用和回存

1. 从`index.json`找到目标流派的当前存档目录。
2. 退出游戏，先备份国服目录中的同名人物，再复制所需文件。
3. 进入游戏“离线”角色列表，选择对应人物实测。
4. 测试通过后，从国服目录回存最新人物，保留修改前版本并更新SHA256校验清单。

本机归档目录为`E:\game\d2rsaves`，国服默认存档目录为`%USERPROFILE%\Saved Games\Diablo II Resurrected (CN)`；其他电脑应使用自己的实际目录。

允许在游戏运行时编辑归档目录中的模板。编辑完成后通知使用者，待游戏退出再复制；覆盖国服目录需要明确授权，不能在游戏运行时覆盖。完整约定见 [归档与测评流程.txt](归档与测评流程.txt)。

## 配装与交付约定

- 毕业装备按正常可获得的属性范围取满变量，互斥词条按BD选择一项。
- 需要破免板时使用相应升级版本，检查实际物品类型和属性。
- 超级野蛮人新版暗金宝珠最多镶嵌一颗，普通彩虹刻面另计。
- 背包留两列安排方块、回城书和辨识书，不要求携带钥匙。
- 所有角色按实际腰带容量填满大紫药水。

## 更新记录规则

每次合入或发布都更新 [CHANGELOG.md](CHANGELOG.md)，说明职业、流派、修改内容、验证结果和兼容性影响。未发布的修改先写入“未发布”；发布时归档到明确版本和日期。

新增流派时同步更新`index.json`和上面的索引表；修改当前存档时更新该目录校验清单和本页当前版本信息。原存档和历史备份保留，不覆盖历史文件来伪造旧版本。

后续协作制作的完整操作手册见 [AGENTS.md](AGENTS.md)，涵盖英雄存档修改器、BD搭配注意事项、实测回存和提交发布流程。
